Concepts You Need

Input resistance RiR_iRi​ describes how much current the next gate draws. A higher value generally loads the driver less. Output resistance RoR_oRo​ describes how easily a load can shift the driver's output voltage. A lower value generally holds the logic level more firmly. Fan-out is the number of gate inputs driven by one output. Identical inputs connected in parallel have equivalent resistance Ri/nR_i/nRi​/n, where nnn is the number of inputs. VOHV_{OH}VOH​ is the high output under the open-circuit or specified loading condition, and VIHV_{IH}VIH​ is the lowest voltage the receiving gate is guaranteed to recognize as high. With the load attached, calculate the loaded output from the voltage divider and compare it with the input threshold.
