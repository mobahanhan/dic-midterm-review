特征尺寸 · feature size

描述工艺可实现的代表性几何尺度。教材常用最小可做的线宽或栅长说明它。具体计算时用设计规则或题目给出的尺寸。

Feature size is aaa representative fabrication dimension, often illustrated by aaa minimum line width or gate length. Use the actual design-rule or problem dimensions for calculation.

棍图 · stick diagram

用线条和交点表示版图中的不同材料层、连线与器件相对位置。多晶硅线跨过有源区可表示晶体管栅，跨层连接要标接触孔或通孔。线条主要表达连接关系和布局顺序。

AAA stick diagram sketches layer connectivity and placement. AAA polysilicon line crossing active material can indicate aaa transistor gate. Contacts and vias mark connections between layers. The drawing conveys topology and placement order.
