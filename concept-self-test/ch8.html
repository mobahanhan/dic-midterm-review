有限状态机 · finite-state machine (FSM)

用有限个离散状态描述系统的记忆。当前状态和输入决定下一状态。输出可只由当前状态决定，也可同时依赖当前输入。

AAA finite-state machine represents memory with aaa finite set of states. Current state and inputs determine the next state. Outputs may depend on state alone or on both state and current inputs.

同步电路 · synchronous circuit

状态更新受共同的时钟基准约束，例如寄存器在时钟有效边沿接收新数据。两次更新之间，组合逻辑有一段时间计算并让信号稳定。

In aaa synchronous circuit,a, a,a common clock reference coordinates state updates. For example, registers accept new data at active clock edges. Combinational logic has time to settle between those updates.

异步电路 · asynchronous circuit

状态变化由输入或局部事件触发，整个系统没有统一的全局时钟边沿来安排更新。一些实现用请求与确认信号表示数据已准备好或已接收。

An asynchronous circuit changes state in response to inputs or local events without aaa shared global clock edge. Some designs use request and acknowledgment signals to indicate that data is ready or received.

锁存器 · latch

电平敏感的存储单元。控制信号处在有效电平时，输出可跟随输入，这时称为透明。控制信号离开有效电平后，保存关闭时的数据。

AAA latch is level-sensitive storage. While the control is at its active level, the output can follow the input. When the latch closes, it retains the data present at closing.

触发器 · edge-triggered flip-flop查看释义收起释义

触发器 · edge-triggered flip-flop

边沿触发的存储单元，在时钟的指定上升沿或下降沿采样输入，在两次有效边沿之间保持采样值。输入应满足建立和保持时间。

AAA flip-flop samples its input at aaa designated rising or falling clock edge and holds the sampled value between active edges. The input must satisfy the setup and hold requirements.

建立时间 · setup time

在采样边沿到来之前，输入至少要提前稳定多久，记为 tsetupt_{setup}tsetup​。数据路径太慢或时钟周期太短，都可能让数据赶不上这个提前量。

Setup time is the minimum interval for which data must be stable before the sampling edge. AAA slow data path or aaa short clock period can leave insufficient setup time.

保持时间 · hold time

采样边沿之后，输入至少还要继续保持稳定多久，记为 tholdt_{hold}thold​。若下一笔数据沿过快的路径立刻到达，可能把刚被采样的数据扰乱。

Hold time is the minimum interval for which the input must remain stable after the sampling edge. AAA very fast path can deliver new data too soon and disturb the value just captured.

传播延时 · propagation delay查看释义收起释义

传播延时 · propagation delay

从输入变化到输出完成响应所需的时间。在波形题里，常取输入和对应输出边沿各自越过电压中点的时间差。在最坏情况时序分析中，用传播延时表示保证输出稳定的上界。

Propagation delay measures how long an input change takes to produce an output response, often between corresponding midpoint crossings. In worst-case digital timing, it bounds the latest time at which the new output is guaranteed valid.

污染延时 · contamination delay查看释义收起释义

污染延时 · contamination delay

输入变化后，输出最早可能开始改变的时间，常记为 tcdt_{cd}tcd​。在此之前旧输出仍保证有效。它用于检查新数据会不会过早到达并违反保持要求。

Contamination delay is the earliest time at which an output may begin to change after an input change. The old output remains valid before that bound. It is used to check whether new data arrives too early for hold timing.

时间约束 · timing constraint查看释义收起释义

时间约束 · timing constraint

时序电路正确采样要求数据到得够早，而且保持得够久。建立检查用数据路径的最大延时，给出时钟周期下限。保持检查用数据路径的最小延时，要求数据不能在同一采样边沿后过早到达。分析时还要计入两端时钟的到达差异。

Timing constraints ensure that data arrives in time and stays valid long enough. The setup check uses maximum data-path delay and constrains the clock period. The hold check uses minimum data-path delay to prevent new data arriving too early. Account for differences in clock arrival times.

时钟偏移 · clock skew查看释义收起释义

时钟偏移 · clock skew

同一个标称时钟边沿到达两个位置的时间差。若定义为接收端到达时间减发送端到达时间，正偏移表示接收端较晚，通常给建立检查更多时间，却使保持检查更紧。

Clock skew is the difference in arrival time of the same nominal clock edge at two locations. With capture time minus launch time as the sign convention, positive skew makes capture later, helping setup while tightening hold.

时钟抖动 · clock jitter查看释义收起释义

时钟抖动 · clock jitter

在同一观察点，实际时钟边沿相对理想时刻提前或延后。边沿间隔因此会变化，时序分析要为这种不确定性预留时间。

Clock jitter is temporal variation of clock edges relative to their ideal positions at aaa given point. It changes the intervals available for timing, so checks allow for this uncertainty.
